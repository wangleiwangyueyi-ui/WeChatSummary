界面怎么找

  1. 顶部切换日常、历史和基础配置。右上“额度管理”添加 Key、建立独立额度组和校准用量，“任务管理”查看和取消当前任务。
  2. 搜索输入后自动筛选，也可点击放大镜或按 Enter。历史页的匹配提示显示在搜索框下面，请在右侧选择目标群聊。
  3. 底部细进度条的红色表示正在执行，绿色表示完成，灰色表示等待或已取消。文字会显示当前阶段。
  4. 任务管理里可暂停或撤销定时计划。暂停可恢复，撤销则移除已保存的计划群聊。“取消当前任务”只结束这一轮。已经提交的远端请求不能撤回。

同组与独立组

  1. 同一项目的多个 Key 共享一份额度。另一个独立项目在下拉框选择“＋ 新建独立额度组”。例如两组各 500 次，合计 1000 次；是否免费以该项目的模型和计费状态为准。

403：已开启白名单，为什么仍失败？

  1. “已启用”只代表检查已打开。PushPlus 还会核对每次请求的出口 IP。浏览器、直连、代理分流或 TUN 可能使用不同出口。软件的 PushPlus 不使用 Gemini 代理；应核对该用户 Token 对应账号中已保存的白名单。不要关闭白名单来回避排查。

领取并填写 API 凭据

  1. Gemini：打开 https://aistudio.google.com/api-keys ，用自己的 Google 账号创建项目/API Key。在“基础配置”填写 Key、模型名称和本地代理地址后保存。免费层是否可用取决于账号、地区与模型；不要把网页版订阅当成 API 免费额度。
  2. PushPlus：打开 https://www.pushplus.plus/ ，按网站指引关注公众号、登录、完成要求的实名认证并复制自己的 Token，填入基础配置。未实名账号不能发送；普通实名账号微信渠道每日 200 次、每分钟 5 次，会员规则另计。具体以账号和官方最新规则为准。
  3. 点击 Gemini API Key 或 PushPlus Token 右侧的“＋ 管理”，可新增、停用或删除备用凭据。先选中一项，填入名称、Key/Token、每日额度，再点击“保存当前凭据/校准”。主项也可以停用。同一服务可填多个凭据；其他模型服务的 Key 不能代替 Gemini Key。
  4. 备用项的额度组默认为 default，表示与主项属于同一项目/账号，共用计数。来自另一个独立项目或账号时，在“额度组”下拉框选择“＋ 新建独立额度组”，软件自动创建组名；填写该项目的每日额度并保存即可，不需要自己编写组名。相同项目的后续 Key 应选择已有的同一额度组，不要重复新建。
  5. 右上方面板同时显示已启用独立组的合计和当前 Key/Token 用量。例如两组各 500 次，合计显示 1000 次；同项目两个 Key 仍只算一组。停用、未填写的项不计入可用总额度。有组的额度未确认时不显示确定的合计或剩余百分比。
  6. Gemini Key、PushPlus Token 标题旁的“获取”可打开官网。V2 图片密钥对 V2 加密图片是必需的；它不是网站发放的 API Key。“获取说明”介绍本机初始化方式，已保存的密钥不必重复提取。
  7. 密钥只填在本机软件，使用 Windows 当前用户加密保存。更换 Windows 用户后不能直接解密。
  8. PushPlus 官网自动校准的设置方法：
  9. 登录 https://www.pushplus.plus/ ，打开“我的 → 开发设置”，启用开放接口。
  10. 按官网要求设置 secretKey，建议至少 32 位随机大小写字母和数字。此密钥不是登录密码，也不是发送 Token。
  11. 将本机请求使用的公网出口 IP 加入官网安全 IP，不能填 127.0.0.1、192.168.x.x 或代理端口。网络或全局/TUN 代理改变后，可能需要更新安全 IP。本软件的 PushPlus 请求不使用 Gemini 代理配置。
  12. 软件中打开“基础配置 → PushPlus Token → ＋ 管理”，选中对应 Token，在 secretKey 输入框填写并保存，再点“同步官网额度”。该接口需要用户 Token，不支持消息 Token。
  13. 403 且官网返回“IP 未授权”时，应核对请求出口与白名单：已启用不等于已匹配。浏览器的代理出口、本机直连出口、TUN/全局代理出口可能不同，也可能随网络改变。以该用户 Token 所属账号里已保存的安全 IP 为准，不要只看任意查 IP 网页。401 常见于未启用开放接口。无需把账号密码或密钥发送给作者或聊天助手。
  14. 启用“保存 secretKey 后自动同步额度”后，启动及空闲时约每 30 分钟查询一次；同一账号不重复查询。每次最多 3 次开放接口查询，不会发送推送消息，也不算作本机面板的微信发送次数。没有 secretKey 也能推送和手工校准。

调用次数与免费额度

  1. 本软件联网服务只有 Gemini 和 PushPlus；图片 OCR、语音识别、数据库复制/解密为本地处理，不收 API 费用，无需额外注册搜索服务或申请其他 API Key。
  2. Gemini 每个文本块调用一次，长内容还需要合并摘要；失败重试会增加请求次数。预检给出分段次数和合并预估，单任务仍受基础配置的最大调用次数保护。手机排版在本机完成，不增加一次专门的 Gemini 排版请求；模板要求作为原有总结提示的一部分，可能影响输入/输出 Token 数量。PushPlus 长报告会按最终 HTML 长度拆分，发送前按实际条数重新检查额度。
  3. Gemini RPD（每日请求数）按项目和模型计，太平洋时间零点重置；还同时限制 RPM（每分钟请求）和 TPM（每分钟 Token）。500 次是当前用户确认的模型额度示例，不是所有账号统一额度。到 Google AI Studio 的 Rate limits 查看自己的数值后填入“额度设置/校准”。改变模型需重新确认额度。
  4. 默认模型为 gemini-3.5-flash-lite。模型下拉选项还有 gemini-4-hydrogen、gemini-3.8-flash、gemini-3.6-flash（2026-11-18 核对官方免费层名单）。429 或 RESOURCE_EXHAUSTED 时依次尝试 gemini-3.8-flash、gemini-3.5-flash-lite，跳过重复项；全部尝试计入单次任务上限，按模型与独立项目分别统计，不能保证服务限流时一定成功。
  5. 顶部显示实际响应模型，日报末尾列出参与分段与合并的实际模型。额度胶囊统计配置中所选模型。打开“任务管理 → 取消当前任务”，界面会立即显示“正在取消”，当前网络请求或本地操作结束后停止。已提交请求无法撤回。主动取消定时任务后，该次不会重试。
  6. PushPlus 在本软件按北京时间自然日统计。面板显示全部已启用独立组的“已用/总上限、预计剩余次数及一位小数比例”，以及当前凭据的名称、用量和统计来源。例如官网已用 3/200，剩余为 197 次、98.5%。本机估算不知道其他程序或升级前的消耗，不能当作官网实时余额；在“＋ 管理”选中凭据，填写官网“今日已用”可校准，随后本机新请求继续累加。详情显示校准来源和时间。失败或网络超时按已尝试请求保守计数。
  7. 按列表顺序使用已启用凭据。已设置的日额度耗尽时，自动使用后续独立额度组，当前凭据面板同步更新；Gemini 明确返回每日额度耗尽时也会切换。分钟请求/Token 限流会等待重试，不通过换 Key 扩大同一项目配额。PushPlus 900 等账号限制错误会停止当次请求，需先到官网排查。全部额度用完时保留本机文件并提示，日额度重置后重新按顺序使用。
  8. 不同 PushPlus 账号的 Token 会将消息发送给各自的接收账号，长报告可能在额度切换后分发到两个账号；请只添加自己授权使用的接收账号。软件不会因为更换凭据而重复发送已完成的报告分段。
  9. Gemini 返回的实际 Token 总数也会记录在额度详情里。Token 是文本计量单位；API Key / PushPlus Token 是凭据，不能把二者与每日请求次数混为一谈。Token 日上限和账户余额未直接接入时会标明未知，不伪造百分比。
  10. 免费本地功能不依赖云端收费；Gemini/PushPlus 是否免费及额度以账号为准。自动回退仅尝试官方列有免费层的模型；已开通计费的项目调用同一模型仍可能收费。

模型选择与自动回退

  1. 默认模型为 gemini-3.5-flash-lite。下拉框提供 gemini-4-hydrogen、gemini-3.8-flash、gemini-3.5-flash-lite、gemini-3.6-flash（2026-11-18 核对官方定价页）。免费层是否可用及额度以你的项目、地区、模型和计费状态为准。
  2. 优先使用所选模型；遇到 429 / RESOURCE_EXHAUSTED，依次尝试 gemini-3.8-flash 和 gemini-3.5-flash-lite，跳过重复项。所有尝试仍计入单次任务上限，并按模型和独立项目分别记录；服务不可用时无法保证发送成功。
  3. 顶部显示本次实际响应模型；日报末尾列出参与分段和合并的实际模型。额度胶囊仍统计配置中所选模型，更换模型并保存后可查看对应额度。
  4. 官方模型：https://ai.google.dev/gemini-api/docs/models
  5. 免费层与价格：https://ai.google.dev/gemini-api/docs/pricing

日常与导出

日常汇总

  1. 搜索并勾选目标群。点击“每日运行时间”旁的按钮，分别选择小时和分钟，再添加一个或多个时间点。点击“应用”返回日常页，再点“保存日常设置”。首次设置或暂停后需要手动启用定时计划。
  2. 手动生成日报会先在本机预检，显示预计 Gemini/PushPlus 次数，确认后才调用云端。仅导出记录使用 0 次外部 API。自动任务将预估写入进度和日志后按已保存的设置运行，不弹窗阻塞后台值守。
  3. 关闭主窗口会隐藏到托盘；从桌面快捷方式或托盘打开设置。开机自启静默运行。电脑关机时不能工作，下次登录、微信启动同步后补跑错过的时段。

历史查询与导出

  1. 输入群关键词，从匹配结果选择目标群；选择近 7 天、近 1 个月、1/3/5/10 年或手填起止时间。近 1 个月从上个月同日零点开始，月底会自动使用有效日期。
  2. 人物栏可填昵称/备注/标识；留空分析全群。可查直接发言和转发内原发言者。
  3. “仅导出记录”生成 Markdown；“导出 + Gemini 复盘 + 手机推送”额外生成分段摘要、阶段复盘 Markdown 和 HTML 阅读版，并按手机卡片模板推送。基础配置可以输入或浏览选择保存目录，保存后对新任务生效；旧文件不会自动搬迁。
  4. 总结按“要点速览 → 话题详情 → 明确事项 → 待办与待确认”组织，资料覆盖由程序统计。不同发言人的观点和来源分开列出，明确事项不等于外部核实。
  5. 使用说明底部可打开“模板预览”，或选择已有摘要 Markdown“本地重排”。后者生成新的 HTML 阅读副本，不覆盖原文，不调用 Gemini，也不发送 PushPlus。旧文本仅改善视觉排版，不自动改写内容逻辑；新的总结任务使用新版结构。
  6. 十年按钮只是时间范围，导出内容取决于本机实际保存的记录。大量图片或语音的本地识别需要时间，进度百分比按阶段和记录数估算，不代表精确耗时。

进度、异常与数据边界

  1. 进度显示：本地预检 → 读取/解析消息（含 OCR/语音）→ 预估确认 → 导出 → Gemini 分段/合并 → PushPlus → 完成。
  2. 进度条运行时为红色，完成后为绿色，取消后为灰色。等待限流重试时进度保留并显示等待原因；失败或取消不显示 100%。未完成摘要时仍保留已导出的记录和已完成的分段摘要。
  3. 调用 Gemini 会向 Google 发送所选聊天文字及 OCR/语音转写文字，PushPlus 接收摘要和异常信息。离线处理降低对微信运行的干扰，但不能承诺“无风控/零封号”。

环境与说明

先准备什么

  1. Windows 10/11 64 位、官方 Windows 微信。安装包自带独立 Python 运行环境；正常使用不需要手动安装 Python 或另开命令行。
  2. 首次安装下载 Setup 主程序包。仅文字导出与 Gemini 汇总不需要图片/语音组件；需要时在“基础配置与初始化 → 图片/语音组件”下载安装，然后勾选相应功能并保存。每位用户使用自己的账号、Key 和 Token，完成本机初始化。
  3. 升级入口为“基础配置与初始化 → 检查更新”。软件从 GitHub Releases 查询正式版本，下载并校验后由用户点击安装；不会在任务运行时安装。常规界面与功能更新只需小型 Update 包，不重复下载模型。安装版个人数据位于 %LOCALAPPDATA%\WeChatSummary，更新和卸载保留该目录。
  4. 手动准备新环境：从 https://www.python.org/downloads/windows/ 安装 Python 3.12 64 位并勾选 Add Python to PATH；在完整软件包目录执行 python -m pip install -r requirements.txt。启动入口为 pythonw.exe wechat_gui.pyw。语音模型和一次性初始化组件需要配套安装，不能只安装依赖就直接读取数据库。
  5. 依赖包括 customtkinter、pycryptodome、lz4、zstandard、rapidocr_onnxruntime、google-genai、requests、Pillow、pystray、sherpa-onnx、pilk-nogil、av、tzdata。离线语音模型放在 models/sensevoice。新电脑必须单独适配、初始化，不能只复制程序和加密凭据就使用。

设置微信与初始化

  1. 在微信设置中开启图片、文件自动下载；保持需要分析的群消息和附件已同步到本机。重点群建议取消折叠，打开群查看最近消息。
  2. 已完成初始化的电脑可以直接使用。首次使用需要在自己的账号上完成数据库密钥及图片密钥初始化；日常运行只复制数据库与附件做离线处理，不操控微信发消息。
  3. 一次性初始化依赖专门适配的临时工具，已完成后会移除。若向导提示组件已移除，请联系作者处理；不要反复扫描微信内存或照搬其他微信版本的提取命令。
  4. 语音先读取微信已有转文字；没有时调用本机模型。未下载附件、已删除记录不能恢复。

工具特点

  1. 日常不注入、不操控微信；本机 OCR 与语音转写；支持本机已保存的近十年记录批量导出，支持定时汇总。十年按钮不能恢复未同步或已删除的内容。
